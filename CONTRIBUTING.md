# Contributing to Treelab

Thank you for taking the time to look at Treelab.

## Issues: yes

Issues are welcome. Open one to:

- report a bug: what you ran, what you expected, what happened, and the output of `lab doctor`;
- ask a question about installing or using Treelab;
- suggest an improvement.

Never paste a licence key, a token, a password or private project data in an issue: this repository is public.

## Pull requests: no

This repository is a mirror of the product. It receives one commit per published version, built from a private repository,
so a pull request cannot be merged here. If you have a fix, describe it in an issue: it will be credited in the release notes
when it ships.
